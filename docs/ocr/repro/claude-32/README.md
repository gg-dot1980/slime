## 候選

- **辨識**：claude-31 的辨識（QHD 讀圖 2000px，加上 Grow46 的 NPC 幾何修正）。另外補上 Grow46 規劃器需要的物件欄位：`labelSeen`、`localReliable`、`originalRadius` 等。
- **小地圖標記**：改用 Grow46 自己的 `growMarkers`（含 `sizeLower`／`sizeUpper`）。
- **決策**：Grow46 的 `planGrow46`（v2.13 用 `planGrow23`，v2.22 用 `planHunt46`，含 v2.22 的吞食提示判讀）。從 [0ec23d98 的 ocr-grow46.html](https://github.com/gg-dot1980/slime/blob/0ec23d98966f04e88aa9c54ec1c5a409597669e9/docs/ocr/repro/grow-46-public/ocr-grow46.html)（planBaseline … planGrow46）原樣複製，包在獨立作用域 `G46` 裡，避免和 Claude 頁面同名的函式互相取代。
- **決策間隔**：100ms，同 Grow46。

每次決策計算時間（QHD，各 40 秒）：
- v2.13：中位 30ms、最大 91ms。
- v2.22：中位 27ms、最大 117ms。
