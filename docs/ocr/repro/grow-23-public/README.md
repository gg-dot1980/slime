## 理由與限制

公開遊戲會先取距玩家650～2100的出生位置，再將座標限制在場地內；靠牆時，這可能把新 NPC 移到玩家接觸範圍。固定數字反例已重現這項機制，但沒有辨識出既有實戰的真正致死 NPC，不能把它當成已確定死因。

額外牆距為 `200 + .72*(HUD+.5+200) + clamp(speed*.17,28,64)`。前半是出生瞬間的靜態接觸幾何界線，後半是有上限的政策緩衝，未被證明能涵蓋所有感知、移動或成長誤差。它可能放棄牆邊獵物、降低成長速度。
