`ocr-grow23.html` 是完整單檔程式，內含控制器與 v2.13／v2.22 隔離遊戲。以 Grow22 為直接父版，保留 NPC 互吃風險規劃。只在 v2.22、HUD 小於186時，於既有模型判為可避敵的路徑中優先保留較大離牆距離；沒有這種路徑時，以已看見的敵人避讓為先。遊戲規則、辨識與控制時序沿用父版。

## 固定實戰計畫

父版 Grow22 的獨立確認為 v2.13 5/12、v2.22 1/12，未達雙版本各 6/12 的樣本門檻，且全部 24 局與終止記錄已完成核對後，才啟用本版。Grow23 先跑兩版各 4 個自然新局；各至少 2 勝且每局都有原生結果，才跑兩版各 12 個額外確認局。失敗與中止保留，不補局、不與父版或探索結果合併。

## 理由與限制

公開遊戲會先取距玩家650～2100的出生位置，再將座標限制在場地內；靠牆時，這可能把新 NPC 移到玩家接觸範圍。固定數字反例已重現這項機制，但沒有辨識出既有實戰的真正致死 NPC，不能把它當成已確定死因。

額外牆距為 `200 + .72*(HUD+.5+200) + clamp(speed*.17,28,64)`。前半是出生瞬間的靜態接觸幾何界線，後半是有上限的政策緩衝，未被證明能涵蓋所有感知、移動或成長誤差。它可能放棄牆邊獵物、降低成長速度。

## 固定檢查

13組純數字案例、64個斷言通過，包括開闊場地、v2.13、免疫狀態、未知牆距及已有互吃規則。保留成長損失反例：原模型預估增長9.504，避牆原型為0。也保留被拒絕的無條件硬牆版本會逼向已知敵人的反例；目前有條件原型在該例維持原本避敵路徑。這些是離線驗證，並非真實遊戲結果。
