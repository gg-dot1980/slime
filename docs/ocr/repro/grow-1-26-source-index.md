## 還原方式

- Grow1–6 在對應提交執行 `node scripts/build.mjs`，向輸出的 Worker 請求 `/ocr-grow` 即得表列頁面。Grow1 嵌入該版專用的隔離遊戲，Grow2–6 由該提交的遊戲版本及嵌入器組裝。
- Grow7–12 從指定提交執行 `node docs/ocr/repro/grow-7/source/reproduce.mjs N /absolute/new-directory`。將 `N` 改成版本編號，輸出在新目錄的 `ocr-grow.html`。每版來源清單記載原始 Sites 提交、逐檔路徑與雜湊。Grow12 模板共用評估包的 `bundle/source/src/ocr-grow.html`。
- Grow13 從指定提交執行 `node docs/ocr/repro/grow-evaluation-20261125/materialize-game-sources.mjs`，切換至同目錄下的 `bundle/source`，再執行 `node experiments/grow13/build-lab.mjs`。輸出 `experiments/grow13/index.html` 與歷史清單雜湊相同。這個實驗頁的 `/lab/harness.js` 由同版的 `server.mjs` 提供。
- Grow14–19 取固定提交中的完整實驗頁，對應資料夾也保存規劃器、實驗腳本或伺服程式。Grow14、15 表列的是當次凍結測試頁。Grow20–26 取對應的獨立候選頁。
