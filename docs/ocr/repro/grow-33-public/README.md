# Grow33 遮蔽追蹤與近距攔截

從 Grow29 延伸，從小地圖點的顏色與面積估計位置與大小，結合短期軌跡與主畫面可靠量測，選擇近距的攔截方向。

從儲存庫根目錄依 [桌機測試說明](../grow-local-r4-20261126/README.md) 啟動本機伺服器，選擇 **Grow33**。[完整控制器](ocr-grow33.html) 的 SHA-256 為 `5caf1539b31686ca20f3169b8934fadd66708929011f9b040eca55c317536a44`。

[可還原的開發來源](../grow-development/grow-33/prototype-sources.json) 列出程式名稱與雜湊。執行 `python3 docs/ocr/repro/grow-development/restore-grow-prototypes.py docs/ocr/repro` 可檢查此提交已包含的原型。
