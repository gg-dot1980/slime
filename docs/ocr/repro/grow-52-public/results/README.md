## 新失敗假說與唯一下一步

兩段最長的 v2.22 停滯發生在仍有可吃 NPC 時：體型 146 停滯 12.5 秒，13 個取樣中改路 10 次；體型 117 停滯 14.6 秒，15 個取樣全部 14 次改路。這比安全間隙門檻更直接指向移動 NPC 攔截時的追逐抖動。

唯一下一步是固定回放這兩段長停滯、體型 187 的近成功截止局及死亡局，僅比較「HUD 未成長且同一可吃 NPC 仍可辨識時，短暫鎖定該目標最多 1.5 秒；每幀重算攔截點與安全路徑，不鎖死方向」。須降低停滯段改路次數、保留正安全間隙，並以 Grow51/Grow52 勝局作相反例；兩組都支持才建立 Grow53。
