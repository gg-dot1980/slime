# Grow52 · 正常安全間隙 14

Grow52 以凍結 Grow51 為父版，只修改 v2.22：正常選路的預測最小安全間隙由 `4` 提高為 `14`。既有逃逸門檻、Grow51 切換路徑安全閘、捕食評分、牆保護及 v2.13 決策均不變。

## 建立依據

原排定的 1.5 秒方向保持已否決。Grow51 確認 ledger 的 1,399 個 v2.22 樣本可 1,399/1,399 精確重現，14 個安全閘觸發亦 14/14 重現；方向保持會同時改動兩個失敗局與唯一觸發勝局。保留的高頻終場 sidecar 另有 506/506 精確重現；方向保持未改動任何死亡樣本。

安全間隙 14 的單項回放則有失敗選擇性：高頻終場 506 個樣本只改動 11 個，全部位於四個死亡局；完整 ledger 1,399 個樣本只改動 7 個，分布於三個死亡局及一個截止局。兩組均未改動勝局。詳見 `validation/replay-summary.json`。

## 重建與檢查

```sh
python3 build.py ../grow-51-public/ocr-grow51.html ocr-grow52.html --check
node check.cjs ocr-grow52.html
```

正式自然測試仍依 QHD 固定探索 v2.13、v2.22 各 4 局；兩版各至少 2/4 且完整才另起各 12 局獨立確認。手機固定組已由 Grow51 完成，本版不重跑手機組。
