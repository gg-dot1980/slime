# Grow50 選中路徑終點間隙趨勢回放

- 狀態：**未支持建立新候選**；本回放只用於開發，不計自然局。
- 來源：Grow50 QHD 自然探索 v2.22 第 1、4 局死亡中，原選路徑 `endGap < 0` 的 5 個保留幀，以及第 2 局勝局相反例。
- 精確性：Grow50 原規劃器在 144/144 個保留決策幀上與 ledger 完全一致。

## 單一比較

只檢查一個假說：選中路徑的 `endGap` 在保持正值時連續兩個取樣下降，能否先於原本 5 個負值事件出現，並在勝局保持不觸發。

| 檢查 | 結果 |
|---|---:|
| 原選路徑負值事件 | 5 |
| 事件前已有連續兩個下降取樣 | 0/5 |
| 緊鄰事件前只有一個正值下降取樣 | 1/5 |
| 事件當幀切換路徑 | 4/5 |
| 約 100–113 ms 內由正值跳為負值 | 3/5 |
| 勝局原選路徑負值事件 | 0 |

第 1 局唯一負值事件距離可見死亡結算約 2.56 秒。第 4 局第一個負值事件距離死亡約 6.46 秒。兩局都存在單幀負值訊號，但事件前的連續下降規則沒有涵蓋任一事件。固定追蹤同一路徑的預測值也顯示，路徑切換使選中序列不連續，不能用簡單斜率可靠預告。

勝局在達體型 200 前保留的決策幀間距較疏，之後的密集幀已進入 `cap200-finish`。因此勝局可以排除已觀察到的負值事件，無法提供等密度的下降趨勢控制樣本。基於死亡涵蓋率 0/5 與此取樣限制，不建立 Grow51。

## 後續假說

下一步只驗證「選中路徑剛切換且 `endGap < 0`」的安全改向是否仍有足夠反應時間。沿用同 5 個事件，逐一核對當幀最大安全間隙路徑的 `wallOK`、`clearance`、首次觸發到死亡的時間，以及勝局是否出現相同切換。兩個死亡組與勝局相反例都支持後，才建立候選。

未修改 Grow50 凍結來源，未啟動新自然局、手機正式局或獨立確認。
