# Grow53 · 三畫面目標速度中位數

Grow53 以凍結 Grow52 為父版，只修改 v2.22：HUD 停滯至少 4 秒且同一可吃 NPC 已連續匹配三個畫面時，以三畫面速度分量中位數取代該 NPC 當幀速度。每幀仍重新選目標、方向與完整 64 條兩段路徑；第一段時長、安全間隙 14、牆保護及 v2.13 決策均不變。

## 建立依據

初步單幀回放後，再以候選實際狀態逐幀接續驗證。Grow52 四個失敗局有 3 次改路：2 次提高預測成長，其中 2 次提高安全間隙，另 1 次安全間隙由 73.0 降至 66.9、仍高於門檻 14；沒有降低預測成長或引入不安全路徑。Grow51 六個勝局只有 1 次改路，預測成長不變且安全間隙由 17.3 增至 151.7。完整基準重現 553/553。詳見 `validation/replay-summary.json`。
