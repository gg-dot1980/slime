## claude-17：白點尺寸記憶

- 用世界座標記住畫面內看過、未裁切的 NPC（位置、半徑，保留 8 秒）。畫面外的白點如果在記憶位置 160 世界 px 內，就沿用記憶的半徑。這樣可以分辨出「其實致命的白點」。
- **修正**：讀到尺寸、落在 0.95R～1.06R 之間的白點，不再當成追獵目標。這個問題從 claude-14 就存在；為了讓已記錄的結果可以重現，這項修正只在 claude-17 以後生效。
- **結果**：0/12 過關。v2.13 是 63、92、68、70、54，另 1 局第 149 秒死時 69；v2.22 是 57、99、77、62、74，另 1 局第 110 秒死時 65。沒有改善（claude-16：v2.13 中位約 51，v2.22 約 100）。

## claude-18：合併巨型 NPC 碎片

- 畫面內的致命項目，如果圓心落在另一個項目半徑 ×0.9 內，就合併，保留較大的，邊緣推算圓優先。小地圖和記憶中的項目不合併。
- **混合版（模擬小地圖＋控制器畫面辨識）v2.22**：123、92、死135/80、92、45、76，中位約 84；吞 NPC 中位 11。claude-16 規則是 66.5／7，**恢復了一部分**。
- **真實控制器 claude-18 v2.22**：72、67、58、85、76、44，中位約 70。**沒有改善**。
