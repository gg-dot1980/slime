## 安全閘觀察與唯一下一步

v2.22 確認的安全閘共在 6/12 局、14 個取樣點觸發；這六局只有 1 勝，另有 3 死亡、2 截止。未觸發的六局則有 3 勝、2 死亡、1 截止。觸發不是失敗的充分條件，但也沒有顯示出足夠的失敗選擇性。

更關鍵的是，14 次觸發中有 13 次只維持一個取樣點；只出現一次連續兩個取樣點。所有仍有下一取樣的事件，下一次方向均再次改變。因此下一步不直接建立新候選：固定回放這 14 個觸發事件，測試在威脅仍逼近且安全間隙仍為正時，短暫保持安全方向、最多 1.5 秒，並以唯一的觸發勝局作相反例。須同時改善觸發死亡／截止組且不破壞勝局，才建立 Grow52。
