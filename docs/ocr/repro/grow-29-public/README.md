# Grow29 小地圖淡白點偵察

Grow29 從 Grow28 延伸，在玩家位置可靠時估算淡白色小點的面積與圓度，排除玩家框、地圖邊緣和近紅點的候選。偵察分數考慮附近白點的數量，以及第一段動作能縮短多少距離。體型達 90 後，補充偵測的淡白點使用 0.40 倍偵察權重。主畫面食物或 NPC 若預計在第二段才接觸，該次成長的折現收益再乘以 0.70。

人工影像回歸包含 25 個非整數位置的白點、錯色、邊沿、紅點干擾及受阻路徑。測試使用 Node 內建模組。

```sh
node docs/ocr/repro/grow-29-public/check-scout.cjs
```

從儲存庫根目錄依 [桌機測試說明](../grow-local-r4-20261126/README.md) 啟動本機伺服器，選擇 **Grow29**。[完整控制器](ocr-grow29.html) 的 SHA-256 為 `c2be01577f298c43d994bb3d433bea7b5dcfeb9d4db4409469282996c7f47e5d`。
