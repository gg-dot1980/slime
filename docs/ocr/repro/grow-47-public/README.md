# Grow47：v2.22 的 1.5 秒預測牆距評分

Grow47 是 Grow46 的單一候選。在原本符合安全檢查的 v2.22 路徑中，加入 Claude22 的預測牆距扣分。此版本保存原捕食收益、威脅分類、硬安全門檻與緊急逃生排序；v2.13 的 Grow38 規劃器完整保留。**本目錄完成時自然遊戲 0 局、瀏覽器與伺服器啟動 0 次。QHD 實際預檢、控制診斷、探索及確認均待執行。**

## 固定假說與來源

[Grow46 確認結果](../grow-46-public/results/README.md)已結案：v2.13 為 10/12、v2.22 為 4/12，後者有 8 次死亡。這 8 局最後可讀的小地圖／HUD 估計身體邊緣距牆均小於 600 世界單位，當中 2 局小於 150。這只是終局附近位置的相關性，不能識別致死個體或證明牆界造成死亡。

本候選只檢驗一個假說：在保留 Grow46 捕食與緊急逃生的條件下，預先降低朝牆路徑的分數，能否減少近牆死亡而不使成長大量轉為逾時。未依合成結果調整距離、權重或新建其他策略。

## 唯一策略改動

Grow46 本來就模擬 64 條兩段方向、每步 0.1 秒、總長 2.2 秒的路徑。Grow47 取相同軌跡前 15 步的玩家中心位置，不另換速度模型。以可見小地圖玩家位置換算世界座標，再減去 HUD 半徑，取得每一步身體邊緣到最近牆壁的估計距離 `d`。世界尺寸沿用現有的 10400×7200。

- 任何前 1.5 秒取樣的 `d < 0`：加入 400 分扣分，停止該路徑的新增牆距累加。
- 尚未發生上述穿牆、且 `d < 150`：在該步加入 `(150-d) × 0.6 / (t+0.3)` 扣分。
- 路徑抵達 1.5 秒、且終點 `d < 600`：再加入 `(600-d) × 0.04` 扣分。Claude22 先保存第 15 步終點才檢查穿牆，因此首次穿牆恰在第 15 步時仍有這一項；更早穿牆則沒有終點項。

距離、時間與權重完整沿用 Claude22。Grow47 使用 Grow46 的慣性和兩段轉向；Claude22 原規劃器用單方向與另一慣性係數。新增評分器停止累加不會中斷 Grow 的原捕食、威脅與 2.2 秒軌跡計算。這是牆距評分規則的移植，並非重現完整 Claude22。

新增分數只有在 Grow46 既有 `wallOK` 與硬威脅 `clearance` 門檻通過後，才從安全池路徑的分數扣除。硬威脅門檻維持 4，前一決策正在逃離時維持 14。無安全路徑時，原緊急逃生公式和用 `score` 比較的次排序均保留；新增牆距扣分不參與該分支。食物／NPC 可食性、紅色標記、半徑不確定性、免疫期、白點偵察、接觸收益與 Grow46 停滯追逐折減皆保留。

新增距離只使用 Claude22 相同的 `map.player` 世界座標來源：`x=map.player.x/map.width*10400`、`y=map.player.y/map.height*7200`，不對該座標額外裁切或限制範圍。Claude 的 `hasMap` 只檢查玩家物件存在且寬高大於 0；本候選沿用 Grow 原有的玩家 x/y 為有限數、寬高大於 0 條件，新增評分器也要求四個換算牆距都是有限數。Grow 原有硬安全檢查仍優先使用 `visibleWalls`，兩者可能不同；本版沒有把兩估計強制合併。小地圖缺失或估計非有限數時，新分數停用，既有主畫面策略仍可能繼續控制。原失效／過期影格與釋鍵條件保留，不能把「沒有新增牆分」解讀成安全已確認。

- 8 個公式邊界逐值符合保存的 Claude 原語句：600、599、150、149、100、0、第一步穿牆、第十五步才穿牆。

## 可公開的診斷欄位

`wall47` 記錄所選軌跡的新評分 `penalty`、前 1.5 秒最小身體邊緣牆距 `min`、終點 `end`、是否預測穿牆及取樣數。逃生分支也可保留估計值，但不套用扣分。

`wallTracking47` 分開記錄評分是否可用／套用、安全池被扣分的路徑數、實際所選路徑扣分、完整 Grow46 評分後的基準方向／牆距、候選方向／牆距及是否改變第一段或任一段方向。`appliedCounts` 只在實際送出控制後累加決策數、有安全路徑被扣分的決策數及改向數；每局歸零。這些是控制器診斷，不是遊戲結果。

追逐折減的 `tracking46.firstChanged/routeChanged` 現在明確比較「牆分之前」的原 Grow46 兩個階段；`preWallFirst/preWallSecond` 保存該階段最後選擇。`tracking46.chosenPenalty` 仍描述真正選中的路徑。`wallTracking47` 另比較該選擇和加入牆分後的選擇，避免把同一個牆改向誤報成追逐折減改向。兩組計數只分解當前輸入的評分次序，不能推論若整局採另一策略會發生的事。
