# Grow31 持續追獵

從 Grow29 延伸。將小地圖位置換算到競技場座標，短暫保留被玩家標記或相機框遮蔽的獵物，並在重見後核對其位置。

從儲存庫根目錄依 [桌機測試說明](../grow-local-r4-20261126/README.md) 啟動本機伺服器，選擇 **Grow31**。[完整控制器](ocr-grow31.html) 的 SHA-256 為 `c7eea92bc8b1698b457d157c5f1d102b69293af3e724cadf312a1833b38461af`。

[可還原的開發來源](../grow-development/grow-31/prototype-sources.json) 列出程式名稱與雜湊。執行 `python3 docs/ocr/repro/grow-development/restore-grow-prototypes.py docs/ocr/repro` 可檢查此提交已包含的原型。
