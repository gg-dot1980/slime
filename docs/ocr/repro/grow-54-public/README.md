# Grow54 · 兩畫面安全後解除逃逸

Grow54 以凍結 Grow53 為父版，只修改 v2.22 的緊急逃逸解除條件。規劃器在安全間隙小於等於 0 時啟動逃逸後，須連續兩個可見畫面的候選安全間隙都至少 14 才解除。方向仍逐畫面重算；若維持逃逸時的正常候選安全間隙小於玩家半徑，或 2.2 秒終點間隙小於 0，才改用既有緊急逃逸排序。Grow53 的速度中位數、成長選路、牆保護及 v2.13 決策均不變。

## 建立依據

回放完整重現 Grow53 兩個死亡局的 211/211 個基準決策。兩個死亡局都在負安全間隙逃逸後只隔一個畫面解除；Grow54 在兩局都改變退路，合計 5 次提高終點安全間隙，沒有新增牆邊卡住。Grow51 六個 v2.22 勝局中，只有 1 次改路，預測成長與安全間隙均未下降，也沒有新增牆邊卡住。詳見 `validation/replay-summary.json`。離線回放僅用於建立候選，不算自然局。

## 重建與檢查

```sh
python3 build.py ../grow-53-public/ocr-grow53.html ocr-grow54.html --check
node check.cjs ocr-grow54.html
```

正式自然測試依 QHD 固定探索 v2.13、v2.22 各 4 局；兩版各至少 2/4 且完整才另起各 12 局獨立確認。既定一次性手機組已由 Grow51 完成，本版不重跑。
