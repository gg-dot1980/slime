# 階段 1b 協議：claude-11 vs claude-21 成對比較（開跑前固定）

2026-11-26（台灣時間）記錄，分支 `ocr-claude`。和[階段 0 協議](../phase0/PROTOCOL.md)相同，只有以下差異：

- **策略**：`STRATEGIES=claude-11,claude-21`，每個策略每版 20 局。
- **claude-21**：claude-20（圓擬合）加上小地圖點大小讀尺寸（`dotSize`）和白點尺寸記憶（`sizeMem`），讀到尺寸落在中性範圍的白點不追。
- **偵測器**：本次加入圓擬合的計算量上限（色塊 >20000 像素就跳過，邊界點最多 300 點），兩個策略都套用。
- **頁面**：`site/ocr-claude21`。
- **決策規則**：claude-21 在至少一個版本的中位數差 95% 信賴區間不含 0（較好），而且另一個版本沒有顯著較差，才採用；否則維持 claude-11。另外檢查死亡數和「致命看成安全」的次數。
