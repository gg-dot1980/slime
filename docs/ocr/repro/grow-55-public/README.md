# Grow55 · 立即間隙優先逃逸

Grow55 以凍結 Grow54 為父版，只修改 v2.22 逃逸保持中的緊急排序。當所有可行路徑的 0.6 秒立即間隙都仍為負時，先最大化立即間隙，再比較 2.2 秒終點間隙；平時沿用 Grow54 的成長選路、兩畫面解除逃逸、速度中位數與牆保護。v2.13 決策不變。

## 建立依據

離線回放只讀 Grow54 兩個死亡局的終端逃逸片段，並以 Grow54 的勝局、體型 194 截止局及 Grow51 六個勝局作相反例。新條件在兩個死亡尾端都觸發並改向，共 6 個決策提高立即間隙，沒有降低勝局預測收益或新增牆邊卡住；相反例均未觸發。這項排序會刻意用較差的較遠期安全間隙換取迫近碰撞時的 0.6 秒退路，因此只進入固定自然探索，不視為已證明改善。詳見 `validation/replay-summary.json`。

## 重建與檢查

```sh
python3 build.py ../grow-54-public/ocr-grow54.html ocr-grow55.html --check
node check.cjs ocr-grow55.html
```

正式自然測試依 QHD 固定探索 v2.13、v2.22 各 4 局；兩版各至少 2/4 且完整才另起各 12 局獨立確認。既定一次性手機組已由 Grow51 完成，本版不重跑。
