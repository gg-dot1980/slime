# 小地圖白點標記遺漏的發現，與 claude-22 vs claude-25

協議：[PROTOCOL.md](PROTOCOL.md)（開跑前固定）。2026-11-26（台灣時間），頁面建置自本次提交的 `src/ocr-claude.html`。

## 發現

小地圖白點標記只在策略名稱清單裡的策略才會計算，**claude-20、claude-22、claude-23、claude-24 沒有被加進清單**。實測（v2.22 各 15 秒，74 拍）：claude-11 和 claude-25 每拍都有標記，平均追獵目標 7.5～7.8 個；claude-20、22、24 全部 74 拍都沒有標記，追獵目標 0 個。

所以下面這些比較，實際上都是在「沒有小地圖白點」的條件下做的：
- 階段 1a（claude-11 vs claude-20）
- 階段 2a（claude-20 vs claude-22）
- 階段 2b（claude-22 vs claude-23）
- 階段 2c（claude-22 vs claude-24）

為了讓已記錄的結果可以重現，claude-20～24 的行為不變，只在程式碼裡加上註記。

## 結果（每策略每版 20 局，實際速度）

| | claude-22（無白點標記） | claude-25（加回白點標記） | 中位數差（22 − 25）[95% CI] |
|---|---|---|---|
| v2.13 體型中位 [95% CI] | 117 [96, 124] | 69 [63, 99] | **+48 [15, 58]** |
| v2.22 體型中位 [95% CI] | 117.5 [90, 124] | 98.5 [83, 113] | +19 [−12, 39] |
| v2.13 過關／死亡 | 0／2 | 0／0（另 1 局排除） | |
| v2.22 過關／死亡 | 0／5 | 0／5 | |
| 每局吞 NPC 中位（v2.13／v2.22） | 9.5／6 | 13／13.5 | |
| 致命看成安全（兩策略合計） | v2.13：0/1173 | v2.22：1/1392 | |

- **決定**：claude-25 在 v2.13 顯著較差（CI 不含 0），依協議確認**在真實控制器上，不追畫面外白點較好，維持 claude-22**。
- **為什麼會這樣**：加回白點後吞 NPC 次數增加（9.5→13、6→13.5），但體型反而變小。一直往畫面外白點移動會犧牲沿路的食物；小地圖位置只精確到約 72 世界 px，追到時獵物也常已經離開或被吃掉。參考機器人的畫面外位置是精確的，結論不同。
- **排除的 1 局**：v2.13 的 claude-25，開局第 2 秒計算逾時（`controller-stop`）。
- 這也解釋了階段 1a 中，claude-20 為什麼比 claude-11 好：主要差別很可能是「不追白點」，不是圓擬合本身。

## 對之後工作的影響

- 混合版和機器人的「追畫面外白點」，不適用於真實控制器，除非小地圖位置變得更精確，或者會先確認獵物還在。
- 之後移植機器人參數時，要用不追白點的版本重新驗證。
