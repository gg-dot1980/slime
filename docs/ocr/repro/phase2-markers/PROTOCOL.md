# 協議：claude-22 vs claude-25（加回小地圖白點標記）成對比較（開跑前固定）

2026-11-26（台灣時間）記錄，分支 `ocr-claude`。

## 背景：發現的錯誤

小地圖白點標記（`whiteDots`＋舊偵測器的紅點）只在策略名稱清單裡的策略才會計算。**claude-20、claude-22、claude-23、claude-24 沒有被加進清單**，所以它們實際上沒有小地圖白點資訊：不追畫面外白點、沒有「裁切物件＋白點」規則，紅點附近的檢查也只剩 `map.threats`。

實測（v2.22 各 15 秒，74 拍）：claude-11 和 claude-25 每拍都有標記，平均追獵目標 7.5～7.8 個；claude-20、22、24 全部 74 拍都沒有標記，追獵目標 0 個。

**對先前結論的影響**：
- 「claude-11 vs claude-20」實際比較的是「有白點追獵」和「圓擬合＋沒有白點追獵」。
- 「claude-20 vs claude-22」「claude-22 vs claude-23」「claude-22 vs claude-24」都是在沒有白點追獵的情況下比較的。
- 為了讓已記錄的結果可以重現，claude-20～24 的行為維持不變。

## 協議

- **候選**：claude-25 = claude-22 加回白點標記流程（和 claude-11 相同）。
- **其他**和[階段 0 協議](../phase0/PROTOCOL.md)相同：`STRATEGIES=claude-22,claude-25`，每個策略每版 20 局，實際速度，v2.13 與 v2.22 同時跑，頁面為 `site/ocr-claude25`。
- **決策規則**：claude-25 在至少一個版本的體型中位數差 95% CI 不含 0（較好），而且另一個版本沒有顯著較差，就採用；顯著較差則確認「不追畫面外白點」較好；兩者皆非則維持 claude-22。
