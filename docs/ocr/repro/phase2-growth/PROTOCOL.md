# 階段 2c 協議：claude-22 vs claude-24（獵物吸引力 3）成對比較（開跑前固定）

2026-11-26（台灣時間）記錄，分支 `ocr-claude`。

## 背景：參考機器人參數篩選（離線工具，3 倍速，只用畫面＋小地圖資訊，規則 v3）

- **篩選**：一次只改一個參數，每組每版 8 局。G（預測 1.5 秒）是 4/8 和 4/8，預設是 1/8 和 1/8；C（吸引力 3）、F（擁擠度 2）也略好於預設。
- **確認**：每版 16 局。G 是 4/16 和 3/16。**G＋C＋F 組合是 8/16（v2.13）和 3/16（v2.22）**，v2.22 的體型中位為 188.5。
- **對應到控制器**：claude-22 的預測時間本來就是 1.5 秒，也沒有擁擠度扣分，所以移植的只有吸引力 6→3。

## 協議

- **候選**：claude-24 = claude-22，獵物吸引力權重從 6 改為 3（`opts.attract=3`）。
- **其他**和[階段 0 協議](../phase0/PROTOCOL.md)相同：`STRATEGIES=claude-22,claude-24`，每個策略每版 20 局，**實際速度**（不加速），v2.13 與 v2.22 同時跑，頁面為 `site/ocr-claude24`。
- **決策規則**：claude-24 在至少一個版本的體型中位數差 95% CI 不含 0（較好），而且另一個版本沒有顯著較差，就採用；否則維持 claude-22。過關數和死亡數一併報告。
