# 決策規則研究（受限全知機器人 v0／v1／v2）與 claude-13

2026-11-25（台灣時間）。分支 `ocr-claude`，接續 [claude-12](../claude-12/README.md)（2ca5e20）。全部為新檔案，或只改本分支新增的檔案。不是 OCR4 驗收。

**線上部署狀態**：使用者告知 ChatGPT 已更新 Sites。從線上 `/ocr-claude` 的選單只到 claude-4 推斷，部署的是 7041c1c，不是 2ca5e20 之後的版本。頁面沒有 commit 編號，這是推斷。

## 結論

- **受限全知機器人**等於辨識完全正確、只用畫面加小地圖資訊的控制器。三種決策規則都達不到每版 50%：

| 規則 | v2.13 過關 | v2.22 過關 | v2.22 死亡 |
|---|---|---|---|
| v0（原規則） | 0/9 | 4/15（27%） | 6/15 |
| v1（2.5 秒預測＋擁擠度扣分＋終點離牆扣分） | 0/6 | 3/12（25%） | 4/12 |
| v2（v1＋路徑上強力避牆、撞牆重扣） | 1/12（8%） | 3/12（25%） | 2/12 |

- **v2 減少了 v2.22 的死亡**（2/12，v0 是 6/15），但過關率沒有提高。150 秒時體型常停在 171～194，差一點。主要缺的是成長速度。
- **v2.13 很難**：v2 的 12 局中，11 局在 150 秒時只有 66～124。
- **claude-13**（claude-12 加上 v2 規則）：0/12，沒有比 claude-11 好。v2.13 是 66～100；v2.22 是 72～109，另有 2 局在第 54、72 秒早期死亡。

## 機器人在 v2.22 的死因（加了凶手紀錄後）

- 原規則的 2 次死亡都發生在體型約 170 時：凶手只大 1.15～1.19 倍，正在追擊，玩家**貼著牆**（離牆 0）。
- v2.22 的 NPC 上限是 200，玩家長到約 185 以上就不會再有致命 NPC。160～185 是最危險的區間，被追到牆邊就逃不掉。v2 的避牆規則就是針對這點。

## claude-13 的實作

- 從小地圖上玩家點的位置換算世界座標，實測誤差中位約 −18px，p10～p90 為 −46～16px。
- 預測 2.5 秒，路徑撞牆扣 400 並中止，離牆 <150px 依時間加權扣分。
- 1.5 秒預測點的擁擠度扣分：Σ(R_i/r)·(250/距離)²×6；終點離牆 <600px 也扣分。
- 合成檢查 62 項。

## 測試條件

- Linux 6.18（雲端），Chrome for Testing 153.0.8010.12 headless，Playwright 1.63.0，Node 22.23.5，視窗 2000×1163，DPR1，視野「標準」。
- 每次兩批同時跑，順序固定，不補跑、不刪除，無 seed。

## 評估與待決事項

- 以目前證據，「v2.13 與 v2.22 各自在 150 秒內 ≥50%」連沒有辨識誤差的機器人都還沒做到。v2.22 約 25%，v2.13 約 0～8%。
- 繼續研究的話，主要要提高成長速度，例如更好的獵物排序、群聚的食物，而不是只改善存活。每個規則至少需要 12～15 局才能分辨差異，每輪約 20～25 分鐘。
- 也可以由使用者決定是否調整目標，例如時間、過關率或版本範圍。本輪不修改 SPEC。
