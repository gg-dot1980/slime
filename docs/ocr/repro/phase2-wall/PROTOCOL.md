# 階段 2a 協議：claude-20 vs claude-22（避牆）成對比較（開跑前固定）

2026-11-26（台灣時間）記錄，分支 `ocr-claude`。

- **基礎版本**：使用者於 2026-11-26 12:51 決定採用 claude-20。claude-20 在階段 1a 的中位數較高，但未達原協議的採用標準。
- **候選**：claude-22 = claude-20 加上避牆，內容同 v2 規則的牆部分：路徑撞牆 −400 並中止；離牆 <150px 扣 (150−d)×0.6/(t+0.3)；1.5 秒預測終點離牆 <600px 扣 (600−d)×0.04。不加擁擠度扣分，預測時間 1.5 秒。
- **其他**和[階段 0 協議](../phase0/PROTOCOL.md)相同：`STRATEGIES=claude-20,claude-22`，每個策略每版 20 局，v2.13 與 v2.22 各一個 runner，同時跑。頁面為 `site/ocr-claude22`。
- **主要觀察**：死亡數，特別是 v2.22，以及結束體型的中位數差（95% CI）。
- **決策規則**：claude-22 的體型中位數差 95% CI 在兩個版本都不顯著較差，而且 v2.22 死亡數較少，就採用；體型顯著較差則不採用。
