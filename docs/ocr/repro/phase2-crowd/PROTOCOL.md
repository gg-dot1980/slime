# 階段 2b 協議：claude-22 vs claude-23（輕度避群＋逃跑維持方向）成對比較（開跑前固定）

2026-11-26（台灣時間）記錄，分支 `ocr-claude`。

- **基礎**：claude-22（階段 2a 採用）。
- **候選**：claude-23 = claude-22 加上兩項：
  - **擁擠度扣分**：在 1.5 秒預測點計算 Σ(R_i/r)·(250/距離)²，權重 2（v2 規則是 6）。
  - **逃跑維持方向**：最佳方向的預測間距 <40 時，如果和前一個方向最接近的候選（夾角內積 >0.9），其間距不比最佳方向差超過 15，就沿用前一個方向。
- **其他**和[階段 0 協議](../phase0/PROTOCOL.md)相同：`STRATEGIES=claude-22,claude-23`，每個策略每版 20 局，v2.13 與 v2.22 同時跑，頁面為 `site/ocr-claude23`。
- **決策規則**：claude-23 在兩個版本的體型中位數差都不顯著較差，而且 v2.22 死亡數較少，就採用；體型顯著較差則不採用；兩者都不明顯時，維持 claude-22。
