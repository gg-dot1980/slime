# Grow49｜v2.22 四局末段回放

原版可見結算為三死一勝，未達探索階段每版本四局至少兩勝的門檻。本次沿用原先四局，在每局結束前約五秒，比對主畫面輪廓、小地圖與規劃器。凍結版程式重算的 149 筆已保存決策皆與當時的選擇相符。相鄰截圖最長相隔約 0.30 秒。

| 分組 | 主畫面與小地圖 | 規劃器判讀 |
| --- | --- | --- |
| 兩個死局 | 各追到一個與其他輪廓重疊、可見半徑約 200 的近身 NPC。末次決策最接近其名字中心的輪廓半徑約 177–181，中心偏差約 19–83 像素。兩局末次決策均無小地圖紅點。 | 兩筆輪廓的半徑上界都已到 200，但只計入風險分數，未進入決定路線可行性的硬威脅淨距。 |
| 一個死局 | 最後 19 筆已保存決策都看得到該 NPC 的名字和危險字樣。回放確認最後三筆決策都把該 NPC 與玩家合為同一色塊，再將整塊當作玩家濾掉。最近的其他 NPC 中心距其名字約 266–277 像素。末筆最接近的粗略紅點中心也偏離約 397 像素。 | 距結束約 0.57 秒曾短暫避險，末次決策又選擇採食探索，仍預測 55 像素正淨距。 |
| 一個勝局 | 玩家附近也有重疊輪廓。最後九筆免疫決策都看得到近身 NPC 的名字，未見配對的危險字樣。HUD 體型為 186，原版結算顯示達到 200。 | 九筆皆處於該版本按體型判定的免疫狀態，威脅數為零。此例可用來檢查近身輪廓引起的誤報。 |

小地圖紅點只標示體型大於玩家 1.12 倍的 NPC，吞噬門檻則是至少 1.08 倍。玩家 HUD 為 183 時，受 200 上限限制的 NPC 仍可能吞噬玩家，但無法達到紅點門檻。

在仍能追到危險字樣的死局，固定已觀測到的 NPC 移動，從結束前約 0.88 秒重算八個方向。按實測玩家位移校正後，提早往東北轉，對該 NPC 的估計最小接觸餘量約為 **+73 像素**，實際軌跡約為 **−2 像素**。對規劃器已記錄硬威脅的最小取樣餘量約 +22 像素，低於模型重建原路線的最大位置誤差約 50 像素。這支持該局提早轉向有機會拉開距離。替代路線能否存活、哪一隻 NPC 最終造成死亡，以及固定順時針轉向的效果，均無法由這四局確認。

**下一步**是把危險字樣仍可見的重疊片段固定成離線回歸案例，檢驗兩個輪廓被合併時，能否利用畫面上仍可見的名字和危險字樣，在濾除玩家時保留該 NPC，並以免疫勝局檢查誤報。
