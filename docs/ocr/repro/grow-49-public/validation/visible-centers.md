## 自然測試條件

沿用原版兩個 Git 遊戲 blob，在本地同源 iframe 執行，QHD 外視窗 2560×1440、原畫布 2250×1308、DPR 1。依序通過既有環境／控制檢查，固定各 4 局探索，兩版各至少 2 勝且完整，才在同一凍結候選下進入各 12 局獨立確認。每勝以 150 遊戲秒內體型達到 200 並出現成功結算為準。取得新的終場原圖時，應一併保留對應辨識、控制、HUD 和時間戳。

本輪先前已啟動的 Grow48 取證程序在 Chromium 建立頁面前停止，v2.13、v2.22 均為零開局。相同環境仍缺少本地 Chromium 執行檔，Grow49 的新自然局待執行。兩份私人檔案保存原圖、逐筆輸出和重算用清單。研究分支僅提供程式與彙總。
