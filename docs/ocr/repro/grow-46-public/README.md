# Grow46 連續追獵距離與第二段收益

Grow46 在 Grow45 的 v2.22 規劃器中，記錄已選本地可食 NPC 的跨幀距離。若持續追逐同一物體而距離反覆未縮短，控制器會折減特定兩段路徑的預測收益。v2.13 使用原 Grow38 規劃器。控制仍取自原遊戲同源 iframe 的可見畫布、HUD 與鍵盤事件。選單沿用 `grow-23`，逐次決策的 `strategy` 在 v2.13 為 `grow-23`，在 v2.22 為 `grow-46`。

## 追逐與計分條件

- 只記錄上一個已採用決策選中的本地可食 NPC。物體須有可信的幾何擬合，且完整可見、未受阻擋。利用小地圖玩家位置和主畫面相對座標轉為世界位置，依上次速度預測位置。候選物體的半徑差不得超過 `max(3, 0.08 × 上次半徑)`。位置門檻依小地圖一個像素的世界距離、觀測時間差換算；有多個可能本體就清除既有追逐紀錄。
- 使用最近一次實際讀取畫面的 `performance.now()` 時間。每個觀察區段至少 600 ms，最多 1500 ms。兩個連續區段的中心距離各縮短至多 6 個世界單位，才形成停滯判定。實測距離比區段起點縮短超過 6 就重新計數。可見 NPC 吞食提示、進入估計接觸範圍、重新選獵物、過期、釋鍵及重新開局也會清除或重建紀錄。
- 在原先符合安全檢查的路徑中，僅當兩段方向不同、首 0.6 秒的預測中心距離縮短至多 6、且同一 NPC 的首次預測接觸落在第二段，才將這次 `g/(t+0.65)` 的折現收益乘以 0.25。食物、其他 NPC、可食與威脅分類、緊急逃生排序、預測物理增長及終點接近分依照 Grow45 計算。
- `planOutput.tracking46` 記錄輸入的影像時間、可見吞食提示、停滯區段、受折減的安全路徑數、選中路徑扣分量，以及同一輸入按原評分會選的兩段方向。`appliedCounts` 累計成功送出控制的決策數、停滯決策數、有安全路徑折減的決策數、改首方向及改任一段方向的決策數。跨局歸零，首方向代表當次實際按鍵方向。

## 固定來源與核對

研究基底 `0ea729163a98ddf464ca4dcfdb4641bf53ce88d6`。父頁 [Grow45](../grow-45-public/ocr-grow45.html) 的 Git blob 為 `b839f06e268a7b866e756b39c2df0ff8e33a0d94`，SHA-256 為 `7f2712f72d46b4bd8ec2a401c66a58f82db661eab5de33d26b355cd7edf8bdcc`。[Grow46 完整頁](ocr-grow46.html) 的 Git blob 為 `7a7127e66abc4ded769fcb00ed13eac2e0e2a658`，SHA-256 為 `2d1e128ecd0efd976a3578158f62ea2d1875105bd4f77d247dcf4c90ca5b87aa`。建置器核對父頁後讀入 [tracking.js](tracking.js)，將追逐判斷接到原控制器的 v2.22 規劃與送鍵流程。

從來源庫根目錄執行。第一行在記憶體重建並核對完整 HTML；加 `--write` 可重新產生候選檔。

```sh
node docs/ocr/repro/grow-46-public/build-candidate.cjs
node docs/ocr/repro/grow-46-public/check-planner.cjs
```

人工可見輸入以 100 ms 間隔重播。正常接近與首次接觸保有原分數；14 個保護案例涵蓋同一性不明、拒判、紅點、碰觸、提示、過期、無地圖與食物。另有一個人工案例在連續 1.2 秒後，有三條安全路徑被折減，選中的首方向由南改為西北。九個其他遊戲版本的完整決策與父版一致。這些都是控制器數值測試，遊戲開局為零。

## 既有決策回放與新自然批次

以既有 Grow45 原生 QHD 的四個 v2.22 遊戲重播可見輸入。原規劃器在 481 個約每秒樣點的兩段方向均相符。因舊樣點未保存每次實際讀圖時間及提示完整顯示期，以三種提示存續假設分別檢查，兩至三個樣點出現停滯，沒有安全路徑同時達折減條件。加入去重後終局鄰近的連續決策，共 593 個觀測，仍無任何路徑折減或方向改變。在 97 個原本只預測第二段接觸的樣點中，62 個在同一或接下來兩個顯示秒有 NPC 提示，這批樣點也全數保留。提示無法識別是否吞到正在追逐的 NPC。歷史沒有完整保存整局的 100 ms 決策，這些回放不能判斷新策略在新局的作用頻率或成績。

此版於凍結時有 0 個自然遊戲開局。QHD 測試採 2560×1440 視窗、預期 2250×1308 原畫布、DPR 1。依 [原生桌機測試說明](../grow-local-r4-20261126/README.md) 安裝 Node.js、Playwright 與 Chromium，於兩個終端執行。`preflight` 僅量測環境。從同批起點選用 `--through explore` 可跑控制診斷、兩款遊戲各四局探索；`--through confirm` 在雙版探索都通過後，才接續每版十二局獨立確認。

```sh
node docs/ocr/repro/grow-local-r4-20261126/server.cjs --geometry-mode qhd --port 4173
python docs/ocr/repro/grow-38-public/geometry/native.py qhd --candidate grow46 --port 4173 --through preflight
```
