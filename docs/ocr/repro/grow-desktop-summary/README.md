## 判定依據

- 兩個原遊戲版本分開計算。依本局可見成功結算及遊戲內耗時判定，150 秒整計為合格。死亡與截止均計為有效失敗。
- 自然探索預訂兩版本交錯各四局，每版至少兩勝且八局均有效才能進入獨立確認。確認門檻為每版至少六勝／十二局。
- 表中分母為有效原生結果。中止、尚未結算與尚未開局的數量另列，保留在批次紀錄。計畫內停止的短診斷不計入。
- 桌機原生瀏覽器從同源載入兩版固定原遊戲，紀錄可見畫面與普通按鍵控制。畫布為遊戲實際像素，DPR 1。各瀏覽器、視野及恢復組分開計算。
