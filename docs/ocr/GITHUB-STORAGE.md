# Slime OCR GitHub 存放規則

- 規則版本：v1
- 建立日期：2026-11-19（台灣時間）
- 適用範圍：`gg-dot1980/slime` 的 `test/ocr-test`。不修改 main、正式站或發布 OCR4。
- 生效點：本文件、交接索引及 r219/r220 固定入口在同一 commit 寫入測試分支且回讀驗證成功後。僅有本機 patch 或未更新分支時為「待同步」，不得宣稱生效。
- 目的：接續者可取得指定版本的完整控制器／靜態分析來源與重新測試條件；不保證重現相同隨機局或取得未上傳影像。

## 每個版本的固定入口

每個可交接輪次使用 `docs/ocr/repro/<輪次>/README.md`，由 [TEST-HANDOFF.md](TEST-HANDOFF.md) 連結。遊戲版本（如 v2.20）、公開測試版（如 test-043）與分析輪次（如 r219）分開標示，不互相代稱。只有入口存在不表示重現資料完整。

入口逐項記錄以下內容；不能取得者明列「未補」「未驗證」或「不可得」，不得猜造：

| 項目 | 必須保存或連結 |
|---|---|
| 版本與來源 | 輪次、策略／測試版本、固定完整 source commit SHA、檔案 hash；commit 不可取得時附完整原始碼或可套用 patch，含明確基底及必要依賴來源 |
| 遊戲 | 實際遊戲版本、遊戲程式／快照 hash、與正式部署是否一致；未核對部署時明示 |
| 環境與依賴 | OS、執行環境、runtime／套件／瀏覽器版本、依賴鎖定檔；視野、DPR、操作方式；真機與模擬分開，未知不補造 |
| 設定 | 所有會影響控制、辨識、記錄及停止條件的設定；與基線差異 |
| 執行方式 | 從乾淨目錄開始的建置、靜態分析、回歸、測試及安全停止命令；額外工具／權限要求與實際執行狀態 |
| 樣本與隨機性 | 固定樣本識別與 hash、開發／留出劃分、seed（若可取得）；未記 seed 明說，不把隨機局當可逐幀重播 |
| 結果 | 每版本／環境的預定局數、所有開局、完成／過關／死亡／逾時／中止／未知分母、時間與結果摘要；中止不能冒充死亡或勝利 |
| 靜態分析 | 來源、測試腳本、可公開且不含像素的輸入／輸出、預期結果、失敗反例及重現限制 |
| 證據與限制 | 哪些已實測、僅離線、僅合成、未驗證；需要本機影像的測試明示不能僅憑 GitHub 重跑 |
| 交接狀態 | 台灣時間更新、阻礙、下一步、遠端 commit／檔案回讀結果及本規則版本 |

結果需區分觀察到的比例與統計不確定性；不能以離線回歸、模型安全分數或診斷局冒充正式實測驗收。現行目標維持桌機 v2.13 起至目前所有指定版本各自 2:30 內過關率至少 50%；手機跳過（非通過）。存放規則不授權降低驗收或發布。

## 允許與排除

保存可重現程式、設定、依賴鎖定、測試腳本、無影像結果與摘要。上傳前逐檔核對，壓縮檔與嵌入內容同樣檢查。

**不得上傳**影像、影片、影格、RGBA／像素陣列、可還原影像的編碼內容、內含像素的 JSON／日誌，或憑證、token、秘密及無關敏感資料。副檔名或「noimages」名稱不是安全證明。可記錄本機影像的樣本 ID／hash 與缺失說明，但不夾帶像素。歷史錯放需明列；移除目前檔案不等於清除 Git 歷史，未另獲授權不得重寫歷史。

## 每次交接的執行流程

1. 核對遠端測試分支 HEAD、適用專案指示及 `.agents/skills`（若存在且相關），讀取有變更的必要證據。
2. 準備固定輪次入口、必要原始碼／patch、依賴、設定、腳本、無像素結果與限制；記錄檔案清單及 hashes。逐項核對上述欄位。
3. 執行能做的乾淨目錄／固定回歸；保留未完成、失敗及未知，不為補檔而重跑歷史或偽造缺失。
4. 同一變更更新輪次入口與交接索引。使用明確檔案清單；禁止整個工作目錄盲目上傳。
5. 僅以已授權正式 GitHub 工具寫入 `test/ocr-test`，基於已讀 HEAD 防止覆蓋其他工作。main、正式站、Library 不在此流程內。
6. 每次寫入後回讀工具產生的物件／commit；分支更新後回讀分支 HEAD、commit 的變更路徑、索引與各檔內容，核對預期內容及 hash。失敗或結果不明先查實際狀態，不能只靠工具已呼叫就宣稱同步。
7. 工具核准未完成或操作遭拒時，保存精確 patch、基底 SHA、目標分支／路徑、拒絕或待核准訊息及未同步範圍。不自行換路徑、帳號或工具繞過。

## 規則增修與同批遷移

每次增修必須在同一變更更新：規則版本、原因、生效點、必要目錄／索引／產生或核驗腳本，以及已知舊連結的相容方案或遷移清單。只有新規則文字、但實際存放仍舊者，不得報新規則已生效。缺項保留為待遷移；不得無聲破壞既有入口。版本紀錄在本文件保留。
